NovelReader 使用说明
====================

这是一款手机上看书的小软件。它可以把 PDF 或 TXT 文件里的文字重新排成
适合手机屏幕的样子，字的大小、行距、背景色都能调，还能做笔记、加书签。
不用联网，也没有广告。

适用版本：v1.5（2026 年 11 月）


一、安装前先确认
----------------
1. 手机系统是 Android 7.0 或更高版本。
2. 手机剩余空间至少有 100 MB（软件本身约 60 MB）。
3. 安装时手机可能提示“未知来源”“不允许安装”，需要在设置里允许
   安装来自浏览器的应用，装完后可以再关掉这个开关。


二、安装
--------
1. 把 NovelReader.apk 传到手机上（数据线、微信文件传输、网盘都行）。
2. 在手机的“文件管理”里找到这个文件，点它。
3. 按提示点“安装”，装完在桌面会出现“NovelReader”图标。


三、导入第一本书
----------------
1. 打开软件，点底部的“导入文件”。
2. 选中手机里的 PDF 或 TXT 文件。
3. PDF 会显示“正在逐页检测文字层”，等进度走完就自动打开。
   页数多的书（几百页）需要等一会儿，中途不要退出软件。
4. 如果 PDF 是扫描件（整页都是图片），打开后会看到“本页正在识别”，
   这是软件在把图片里的字认出来，一页通常几秒。


四、怎么翻页
------------
- 点屏幕左边三分之一：上一页
- 点屏幕右边三分之一：下一页
- 点屏幕中间：呼出菜单（再点一次空白处关闭）


五、菜单里都能调什么
--------------------
菜单从下往上依次是：

字号   - / +        调字体大小，改完自动重新排版
行距   - / +        调行与行之间的距离
边距   - / +        调文字离屏幕边缘的远近
背景   日间/护眼/米黄/深色    四种阅读底色。选“深色”后，书架、菜单、
                  手机顶部的状态栏也会一起变深，不用再单独设置
图片页 单独显示 / 仅文字      扫描页是显示原图，还是只显示认出来的文字
排版   高度还原 / 普通重排    段落之间要不要多留空行

下面一排按钮：

查看原页    看这一页 PDF 本来的样子（用来核对认字有没有错）
全屏看图    图片页全屏查看
重排版面    按最新的规则重新分析整本书（老版本导入的书用这个，
            已经认好的文字不会丢）
目录        章节列表，有书签的 PDF 会按真实章节显示，点一下就跳过去
回首页      回到书架

最下面还有：

加书签 / 取消书签   给当前页做个记号
书签列表            看所有书签，点一条跳回原页
批注列表            看整本书的笔记，点一条跳到原句
整页笔记            给这一页写一段笔记（图片页也能写）
导出                把书签和笔记导出成文件，方便备份
失败页              哪几页认字失败，列出原因，可以单独重试


六、做笔记（批注）
------------------
1. 在正文上“长按”约半秒，不要滑动。
2. 弹出“选中文字”，显示软件自动选中的一整句话。
3. 选“高亮”只做标记；选“高亮并写笔记”可以再写几句话。
4. 以后点一下有颜色的句子，可以改笔记、换颜色或删掉。
5. 菜单里的“批注列表”能看到全书所有笔记，点一条就跳到原句。


七、书签
--------
菜单里点“加书签”，页面右上角会出现星号；再点一次“取消书签”去掉。
“书签列表”里能看到每一处书签和添加时间。


八、扫描版 PDF（整页图片的书）
------------------------------
1. 打开后会自动一页一页识别，标题栏会显示“OCR 3/40”这样的进度。
2. 识别时先保证正在看的那一页和附近的页先完成，可以正常往下翻。
3. 想暂停就在菜单里点“取消识别”；想接着做点“继续识别”。
4. 已经识别过的页会保存下来，关掉软件再打开不用重新识别。
5. 完全是空白的页会显示“本页空白，可直接翻页”，这不是出错。
6. 确实认不出的页会记成“失败页”，菜单里能看到页号和原因，
   点“重试失败页”会重新试一次。建议用“查看原页”对照一下，
   有些页是扫描太模糊或竖排文字，软件识别不了。
7. 扫描书的目录页会自动按条显示：一条目录一行，标题和页码分开，
   不会再把“93三、中国共产党……”粘成一段。以前导入过的书需要
   重新导入一次才会用上这个处理（见第十二节）。


九、阅读进度
------------
不用手动保存。翻到哪一页、看到哪一句，退出软件时会自动记下来，
下次打开这本书直接回到原来的位置。换字号、转横屏之后也不会跑丢。


十、书和笔记存在哪里
--------------------
- 所有内容都存在软件自己的目录里，不会改你手机里原来的 PDF。
- 想删掉一本书：在书架页面“长按”书名，确认删除即可。
- 导出的笔记在手机的
  Android/data/com.dsh.novelreader/files/exports/ 文件夹里，
  里面有两个文件：.md 是给笔记软件看的，.json 是给电脑备份用的。
- 注意：卸载软件会把这些内容一起删掉，卸载前记得先“导出”。


十一、常见问题
--------------
问：点“导入文件”没反应？
答：可能是文件选择器里没有 PDF 权限，换个文件管理器再试一次；
    或者确认文件确实是 .pdf / .txt 结尾。

问：导入一本书要等很久？
答：页数越多越慢，几百页的书需要一两分钟，进度条在走就正常。

问：字太大了，一页没几行？
答：菜单里把“字号”调小、“行距”调小，或者把“边距”调小。

问：目录里只有“第 1 页、第 2 页”，没有章节名？
答：这本书的 PDF 文件本身没有章节信息，软件只能按页列出来。
    有章节信息的书会自动显示章节名。

问：扫描页识别出来的字有错？
答：这是识别本身的局限。可以点“查看原页”对照原文，
    或者把这一页当成图片看（菜单里“图片页”选“单独显示”）。

问：换手机怎么办？
答：把原来的 PDF 文件带到新手机重新导入即可。书签和笔记不会跟着走，
    需要先在旧手机“导出”，新手机再手动对照着加。

问：会不会偷偷联网、上传我的书？
答：不会。软件没有申请联网权限，也没有存储权限，所有处理都在手机上完成。

问：选了“深色”，只有看书页面变黑，书架还是白的？
答：v1.5 起深色会同时应用到书架、菜单和状态栏。如果书架仍是白的，
    请确认安装的是最新版本（书架右上角会显示 v1.5）。

问：段落之间挨得太紧，读不出哪里是新的一段？
答：v1.5 起软件会自动在段落之间留出比行距更大的空隙。如果还嫌紧，
    可以把“行距”调大一点，或在“排版”里选“高度还原”，段间会再多空一行。

问：以前导入的扫描书，目录还是挤成一团？
答：旧版本的识别结果已经存下来了。请在书架长按这本书的书名，选“删除”，
    再重新导入同一个 PDF，等识别跑完，目录就会按条显示。

问：段落间隙太大，一页放不下多少字？
答：把“行距”调小，或在“排版”里选“普通重排”，段间的额外空行会少一些。

问：想换字体怎么办？
答：v1.5 起正文跟随手机系统字体。在手机的“显示 / 字体”设置里换字体后，
    重新打开软件即可生效，软件内不单独提供字体选择。


十二、v1.5 更新内容
------------------
1. 深色模式全局生效：书架、书名、导入按钮、分隔线、状态栏一起变深，
   从阅读页返回时自动刷新。
2. 正文字体跟随手机系统字体，不再固定为宋体样式。
3. 段落之间新增明显间距（比行距更大），段落不再和普通换行混在一起；
   “高度还原”模式下段间还会再多留空行。
4. 扫描书目录页修复：目录按条显示，前导点省略号和页码单独处理，
   不会出现“93三、……”这类两条目录粘在一起的情况；正文的 OCR 也会
   按句子把逐行内容重新合并成段落。
5. 已导入的扫描书要应用第 4 条，需要删除后重新导入（长按书名 → 删除，
   再点“导入文件”选同一个文件）。
